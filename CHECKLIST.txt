📱 HOW TO USE THE APP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Allow Location Access
   → Browser will ask for permission (required for GPS)

2. Save Your Parking Spot
   → Click "Save My Spot" button when you park
   → Timestamp of save is recorded

3. View Distance
   → Real-time distance shows how far you are from your car
   → Updates automatically as you move

4. Navigate on Map
   → Interactive map shows your location and parking spot
   → 50m radius circle marks parking area

5. Clear When Done
   → Click "Clear Spot" once you've found your car
   → Data is removed from storage

🔧 TECHNICAL ARCHITECTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STATE MANAGEMENT
  • parkingSpot: Stores saved location & timestamp
  • currentLocation: User's current GPS position
  • distance: Calculated distance in kilometers
  • error: User-facing error messages
  • loading: Initial load state

GEOLOCATION
  • Method: navigator.geolocation.watchPosition()
  • Accuracy: High accuracy enabled
  • Timeout: 5 seconds
  • Update frequency: Continuous

DISTANCE CALCULATION
  • Formula: Haversine great-circle distance
  • Input: Two GPS coordinates (lat, lng)
  • Output: Distance in kilometers
  • Precision: 2 decimal places

DATA PERSISTENCE
  • Storage: Browser LocalStorage
  • Key: 'parkingSpot'
  • Format: JSON stringified object
  • Lifetime: Until user clicks "Clear"
